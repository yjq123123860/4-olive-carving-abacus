# 算盘 · 出海推演

> 售价、年销量、汇率、获客成本、平台抽成五项参数拖动即算，实时给出净利、净利率与工价回流比例。

## 这是什么

「算盘 · 出海推演」是 **小众非遗出海调查**（增城榄雕非遗出海调查）可视化演示原型之一。

四个演示原型合起来对应报告提出的
「文化资源—叙事解释—境外触达—消费转化—收益回流—文化反馈」六环节价值链：

| 原型 | 对应环节 | 说明 |
|---|---|---|
| 长卷 · 从果到核 | 文化资源 + 叙事解释 | 工艺流程可视化 |
| 陈列馆 · 18 件馆藏 | 文化资源呈现 | 成果体系实物化 |
| 检视台 · 核舟微刻 | 叙事解释 + 境外触达 | 工艺精度佐证 |
| 算盘 · 出海推演 | 消费转化 + 收益回流 | 收益模型可计算 |

## 本页技术特征

- **完全离线**：所有图片、字体、脚本内嵌在单个 HTML 文件中，零外部请求
- **无需安装**：双击 `index.html` 即可打开，不需要服务器
- **数据来源**：增城榄雕非遗出海认知与传播调查问卷（N = 238）、
  传承人访谈、苏绣与桂林团扇商业资料审计

## 开启 GitHub Pages

1. 进入本仓库 → **Settings** → **Pages**
2. Source 选 **Deploy from a branch**，Branch 选 **main**、目录选 **/(root)**
3. 保存，等1–2 分钟
4. 页面顶部会出现网址，形如 `https://你的用户名.github.io/4-olive-carving-abacus/`

页面使用现代 CSS 与 Canvas/WebGL，Internet Explorer 无法渲染。
若双击后一片空白，请右键文件 → 打开方式 → Chrome 或 Edge。
